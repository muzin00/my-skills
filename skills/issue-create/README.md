# issue-create

必要に応じて内容を確認し、GitHub Issueを自動作成するSkillです。

## 使い方

Codexでは、Skill名とIssueの概要を指定します。

```text
$issue-create ログイン後に元のページへ戻れない
```

Claude Codeでは、スラッシュコマンドとして呼び出します。

```text
/issue-create ログイン後に元のページへ戻れない
```

概要を省略した場合や情報が不足している場合は、Issueの種類、変更・修正したい内容、背景や目的を必要な範囲で確認します。

## 実行内容

1. 対象リポジトリを確認する
2. リポジトリのIssueテンプレートと既存ラベルを確認する
3. 類似する未解決Issueがないか検索し、明確な重複候補があれば作成せず報告する
4. リポジトリの言語と書式に合わせてタイトルと本文を作成する
5. `gh issue create --assignee "@me"`で自分を担当者に設定してIssueを作成し、URLを報告する

Issue作成の明示的な依頼を実行許可として扱うため、作成直前の確認は行いません。ただし、対象リポジトリなど作成に不可欠な情報が不足している場合は質問します。

存在しないラベルや、不明な要件、再現手順、受け入れ条件を勝手に作ることはありません。担当者にはGitHub CLIで認証中の自分だけを設定し、明示的に依頼されない限り、ほかの担当者、Project、Milestoneは設定しません。

## 前提条件

- GitHub CLI（`gh`）がインストールされ、対象リポジトリを参照・操作できる状態であること
