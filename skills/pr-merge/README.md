# pr-merge

現在のGitブランチに対応するPull Requestを確認し、安全にsquash mergeするSkillです。マージ後はPRのベースブランチへ切り替えて最新化します。

## 使い方

Codexでは、現在のブランチでSkillを指定します。

```text
$pr-merge 現在のブランチのPRをマージして
```

Claude Codeでは、スラッシュコマンドとして呼び出します。

```text
/pr-merge
```

## 実行内容

1. 未コミットの変更がない作業ブランチで、PRの状態、レビュー、CI、ベースブランチをまとめて取得する
2. draft、変更要求、CI失敗・キャンセルがあれば停止する。CI実行中も状態を報告して終了し、待機は明示的に依頼された場合だけ行う
3. PRをsquash mergeして作業ブランチを削除し、マージ済みか確認する
4. ベースブランチへ戻って最新化する。`gh`が切り替え・更新済みなら、重複するcheckoutやpullを省略する

Skillの明示的な実行を、マージとブランチ削除の許可として扱い、途中でユーザー確認は行いません。競合や保護ルールの判定はGitHubに任せ、管理者権限などで回避しません。

マージキューへ追加された場合は、ローカルブランチを変更せず、その状態を報告します。マージ成功後のブランチ整理や更新に失敗した場合は、マージ結果とは分けて報告します。

## 前提条件

- Gitリポジトリ内のPR作成済みブランチで実行すること
- GitHub CLI（`gh`）がインストールされ、対象リポジトリを操作できる状態であること
