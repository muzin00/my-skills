# pr-merge

現在のGitブランチに対応するPull Requestを確認し、安全にsquash mergeするSkillです。マージ後はPRのベースブランチへ切り替えて最新化します。

## 使い方

Codexでは、現在のブランチでSkillを指定します。

```text
$pr-merge 現在のブランチのPRをマージして
```

Claude Codeでは、スラッシュコマンドとして呼び出します。

```text
/pr-merge
```

## 実行内容

1. Gitリポジトリであることと、未コミットの変更がないことを確認する
2. 現在のブランチに対応するPRの状態、レビュー、CI、ベースブランチを取得する
3. 実行中のCIがあれば完了まで待機する
4. draft、変更要求、CI失敗、競合、ブロックがあればマージせず終了する
5. PRをsquash mergeし、作業ブランチを削除する
6. PRのベースブランチへ切り替え、fast-forwardのみで最新化する

GitHubの保護ルールを管理者権限などで回避することはありません。マージキューへ追加された場合は、ローカルブランチを変更せず、その状態を報告します。

## 前提条件

- Gitリポジトリ内のPR作成済みブランチで実行すること
- GitHub CLI（`gh`）がインストールされ、対象リポジトリを操作できる状態であること
