# pr-create

現在の作業に関係する変更をコミットし、pushしてPull Requestを作成するSkillです。コミット済みならコミットを省略し、既存PRがあればpushしてそのURLを返します。

## 使い方

Codexでは、作業完了後にSkillを指定します。

```text
$pr-create
```

Claude Codeでは、スラッシュコマンドとして呼び出します。

```text
/pr-create
```

## 実行内容

1. 作業状態、ブランチ、既存PRを確認する。デフォルトブランチの取得はローカル情報を優先する
2. 未コミットの関連変更があれば、明示的なパスだけをステージし、差分を確認して英語のConventional Commits形式でコミットする
3. 新規PRの場合だけベースブランチをfetchし、ブランチ全体のコミットと差分を確認する
4. forceを使わずpushする。既存PRがあれば、そのURLを返して終了する
5. ブランチ全体を説明するタイトルと本文で、自分を担当者にしてPRを作成する

Skillの明示的な実行を、ステージング、commit、push、PR作成の許可として扱います。途中でユーザー確認は行いません。

作業中に確認済みの差分や成功済みの検証結果を再利用し、関連する変更がない限り再実行しません。本文は一時ファイルから渡します。

無関係な変更はステージ済みのものも含めてコミットに混ぜず、機密情報もコミットしません。detached HEAD、デフォルトブランチ上、新規PRに含めるコミットがない場合、処理に失敗した場合は停止して理由を報告します。

## 前提条件

- Gitリポジトリ内の作業ブランチで実行すること
- GitHub CLI（`gh`）がインストールされ、対象リポジトリを操作できる状態であること
