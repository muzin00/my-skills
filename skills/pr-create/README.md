# pr-create

現在の作業に関係する変更があればコミットし、pushしてPull Requestを作成するまでを連続して行うSkillです。変更がすでにコミット済みの場合は、新しいコミットを作成せずにPull Requestを作成できます。

## 使い方

Codexでは、作業完了後にSkillを指定します。

```text
$pr-create
```

Claude Codeでは、スラッシュコマンドとして呼び出します。

```text
/pr-create
```

## 実行内容

1. 現在のブランチとリポジトリのデフォルトブランチを確認する
2. 未コミットの変更があれば、現在の作業に関係するものだけを明示的にステージする
3. ステージ済みの差分を検証し、英語のConventional Commits形式でコミットする
4. ベースブランチとの差分となるコミットがあることを確認する
5. forceを使わず現在のブランチをpushする
6. 既存のオープンなPRがないことを確認する
7. ベースブランチとの差分全体からPRタイトルと本文を生成する
8. 自分を担当者に設定してPRを作成する

Skillの明示的な実行を、ステージング、commit、push、PR作成の許可として扱います。途中でユーザー確認は行いません。

`git add .`や`git add -A`は使用せず、無関係な変更や機密情報の可能性があるファイルはステージしません。未コミットの変更がない場合はコミット作成だけを省略し、PR対象のコミットがあれば処理を続けます。デフォルトブランチ上、PR対象のコミットがない場合、処理に失敗した場合は、その時点で停止して理由を報告します。

現在のブランチにオープンなPRがすでにある場合は、コミットをpushしたうえで新しいPRを重複作成せず、既存PRのURLを報告します。

## 前提条件

- Gitリポジトリ内の作業ブランチで実行すること
- GitHub CLI（`gh`）がインストールされ、対象リポジトリを操作できる状態であること
